# 🎵 Музыкальный стриминговый сервис «Bragi Notes»

## 🚀 Инструкция по развертыванию и запуску

Проект полностью контейнеризирован. Для сборки и одновременного запуска всех микросервисов приложения (СУБД, бэкенд, фронтенд) выполните в корневой директории репозитория следующую команду:

```bash
docker compose up --build
```

### 📋 Важные шаги после запуска:

1.  **Настройка видимости портов:** В среде разработки (GitHub Codespaces) необходимо во вкладке **Ports** перевести порты **8000** (бэкенд-сервер) и **5173** (фронтенд-клиент) в режим **Public**.
2.  **Инициализация базы данных (Seeding):** При первом запуске необходимо сгенерировать структуру таблиц в PostgreSQL и наполнить сервис демонстрационным аудио-контентом. Для этого отправьте GET-запрос на эндпоинт инициализации:
    ```text
    http://localhost:8000/seed
    ```
    *(При работе в Codespaces замените localhost на публичный адрес вашего бэкенд-контейнера).*
3.  **Демонстрационные учетные записи:**
    *   **Администратор:** логин `admin` / пароль `admin`
    *   **Тестовый пользователь:** логин `sanya` / пароль `123`
