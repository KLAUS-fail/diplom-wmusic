# 🎵 Музыкальный стриминговый сервис «Bragi Notes»

Дипломный проект представляет собой клиент-серверное веб-приложение (микросервисную архитектуру) для каталогизации, стриминга музыкальных произведений, ведения пользовательских плейлистов и системы избранного.

## 🛠 Стек технологий

*   **Контейнеризация и оркестрация:** Docker, Docker Compose
*   **Автоматизация (CI/CD):** GitHub Actions

*   **Клиентская часть:** JavaScript, React (Vite), HTML5/CSS3

## 🚀 Инструкция по развертыванию и запуску

Проект полностью контейнеризирован. Для сборки и одновременного запуска всех микросервисов приложения (СУБД, бэкенд, фронтенд) выполните в корневой директории репозитория следующую команду:

```bash
docker compose up --build
```

### 📋 Важные шаги после запуска:

1.  **Видимость портов:** В GitHub Codespaces сделайте порты **8000** (бэкенд) и **5173** (фронтенд) **Public**.
2.  **Инициализация (Seeding):** Для наполнения базы данных демо-контентом, перейдите по адресу:
    `http://localhost:8000/seed?secret_key=diplom_bragi2026`
    *(Замените localhost на публичный адрес при необходимости. Без ключа сервер выведет ошибку).*
